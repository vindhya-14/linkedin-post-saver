# LinkedIn Post Saver Chrome Extension

## Overview

This Chrome extension allows users to easily save and categorize LinkedIn posts into GitHub or Notion based on their content. It helps professionals organize valuable insights and content directly from LinkedIn into their preferred storage platforms for easy access, reference, and future sharing.

## Features

- **Save LinkedIn Posts**: Capture posts directly from LinkedIn and save them to GitHub or Notion.
- **Content Categorization**: Automatically categorize posts based on keywords, topics, or content type.
- **Easy Integration**: Seamless integration with GitHub or Notion for efficient content management.
- **User-Friendly**: Simple interface to save and categorize posts with minimal clicks.
- **Customizable**: Allow users to define categories based on their needs.

## Technologies Used

- **JavaScript**: For building the Chrome extension logic.
- **Chrome Extensions API**: For integrating with the browser and LinkedIn.
- **GitHub API / Notion API**: To automate saving posts to the respective platforms.
- **HTML/CSS**: For the front-end user interface of the extension.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/linkedIn-post-saver.git
   ```

2. Navigate to `chrome://extensions` in your Chrome browser.

3. Enable **Developer Mode** at the top-right corner.

4. Click **Load unpacked** and select the project directory.

5. The extension will now be active in your browser.

## Usage

1. After installation, the extension icon will appear in the top-right corner of your Chrome browser.

2. When browsing LinkedIn, click on the extension icon to save a post.

3. Choose your preferred platform (GitHub or Notion) to store the post.

4. The post will be categorized automatically based on predefined content tags. You can customize these categories in the extension settings.

## Customization

You can modify the categorization rules by adjusting the keyword filters in the extension settings. Update the GitHub or Notion integration settings as needed to match your personal workflow.
